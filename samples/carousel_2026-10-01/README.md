# 대표가 만든 캐러셀 샘플 (2026-10-01 업로드) - 이 폴더가 레이아웃의 정답이다

- `샘플1~7.png` = **병(丙)일생 세트**(편집기 이전 상태, 구버전). `정-1~7.png` = **정(丁)일생 세트**(최신 확정본)
- 새 캐러셀은 정 세트를 기준으로 만든다. `pipeline/carousel_editor.py`가 이 샘플을 픽셀로 재서 편집기 파라미터에 넣은 것이고, `python3 pipeline/carousel_editor.py --compare` 가 이 폴더의 정-N.png 와 렌더를 비교한다(SAMPLE_DIR 환경변수로 경로 지정)
- 병 세트와 정 세트의 차이: 표지 부제 위치(정은 제목 위), AI 문구(정 표지에만), 본문 배경 밴드 위치, 오행 차트 배경(병은 없음, 정은 음양 이미지)
- 오행 차트 배경 음양 이미지 원본은 이 폴더에 없다(편집기에 업로드한 이미지). 지금은 정-5에서 복원한 `pipeline/assets/chart_plate.png` 사용
