# SNS STUDIO

브랜드가 바뀌어도 템플릿과 규칙은 그대로 쓴다. 브랜드마다 바뀌는 것은
`brands/<id>.json` 한 개뿐이다.

## 폴더

```
brands/        브랜드 파라미터 (색·글꼴·고정문구·말투·금지표현)
               zaoseon.json  _template.json(새 브랜드용 복사본)
templates/     layouts.css - 레이아웃 5종 + 가독성 기법 4종 + 안전영역
scripts/       render.mjs        대본 JSON → PNG
               build_catalog.py  저장소 에셋 색인
               qa.py             규칙 검사
assets/fonts/  Pretendard 4종
catalog.json   저장소 에셋 3,165개 색인
examples/      대본 JSON 본보기
```

## 만드는 순서

1. 브랜드 파일을 고른다. 없으면 `brands/_template.json`을 복사해 만든다.
2. 대본 JSON을 쓴다. `examples/layout-sheet.json`을 본보기로 쓴다.
3. `node scripts/render.mjs <대본.json> <출력폴더>` 로 PNG를 뽑는다.
4. `python3 scripts/qa.py <대본.json>` 으로 규칙을 검사한다.
5. 영상이 필요하면 하이퍼프레임스로 렌더한다(아래).

## 레이아웃 5종

1만 팔로워 이상 50개 계정의 썸네일을 분석한 결과 레이아웃은 5종으로 압축된다.
한 가지만 반복하지 않고 돌려 쓴다.

| 코드 | 이름 | 쓰는 곳 |
|---|---|---|
| L1 | 좌상단 제목형 | 글은 위, 아래는 캐릭터나 사진에 내준다 |
| L2 | 중앙 집중형 | 한 화면 한 메시지. 훅·명언형 |
| L3 | 상단 띠형 | 위 띠에 글, 아래는 사진 |
| L4 | 하단 띠형 | 위는 사진, 아래 띠에 글. CTA를 같이 둔다 |
| L5 | 좌측 3줄형 | 질문·답 구조. 줄 길이를 일부러 다르게 |

## 가독성 기법 4종

| 코드 | 기법 |
|---|---|
| T1 | 배경에 이미지를 넣는다 |
| T2 | 글자 밑에 그라데이션을 깔아 읽히게 한다 |
| T3 | 연재 배지와 번호를 달아 시리즈로 쌓는다 |
| T4 | 글자 크기를 키운다. 한 화면 한 메시지일 때만 쓴다 |

## 고정 규칙

- 규격: 릴스 1080x1920, 캐러셀 1080x1440, 정사각 1080x1080. 30fps H.264.
- 안전영역(릴스): 위 285px, 아래 320px, 좌우 90px.
  위 285px는 인스타 4:5 피드 잘림선, 아래 320px는 버튼 영역이다.
- 글자: 줄간격 1.4. 단색. 그림자 금지. 단어 중간 줄바꿈 금지
  (`word-break: keep-all` 이 막는다). 한 줄 12~16자.
- 고정 표기: 왼쪽 위 브랜드 이름, 오른쪽 위 한 줄 설명. 모든 화면에 넣는다.
- 표지와 CTA는 반드시 있어야 한다. CTA는 게시물당 한 개만 둔다.
- 캐릭터가 보이는 화면에만 AI 고지를 왼쪽 아래에 넣는다.
- 글이 자리를 넘치면 render.mjs 가 자동으로 줄인다. 잘린 채로 나가지 않는다.

## 영상으로 만들 때

하이퍼프레임스(HeyGen, Apache-2.0, 무료)를 쓴다. HTML로 장면을 짜서 MP4로 뽑는다.

```bash
export HYPERFRAMES_BROWSER_PATH=<크롬 경로>
npx -y hyperframes init <이름> --example blank --resolution portrait
npx -y hyperframes check     # 레이아웃·대비·모션 검사
npx -y hyperframes render -o out.mp4
```

자막 파일(SRT) 한 블록이 장면 하나가 된다. 장면 시간은 자막 시간을 그대로 쓴다.
`check` 가 글자 잘림·대비·모션을 먼저 잡는다.

## 영상 장면 역할 6종

한 편 20초 기준. 모든 컷을 같은 길이로 만들지 않는다.

| 역할 | 길이 | 내용 |
|---|---|---|
| S1 | 0.7~1.2초 | 스크롤을 멈추는 첫 화면. 0.5초 안에 읽혀야 한다 |
| S2 | 0.6~1.0초 x2 | 문제·불편 |
| S3 | 1.0~1.8초 x2 | 핵심 내용 |
| S4 | 0.8초 x2 | 전후 비교 |
| S5 | 1.0~1.5초 | 한계·조건. 신뢰 장치다 |
| S6 | 1.5~2.0초 | CTA |

## 쓰는 순서가 중요하다

사람은 "상황 → 반응 → 왜 필요한지 → 해결 → 제품 → 결과" 순서로 읽는다.
"우리 서비스는 여섯 운명학을 봅니다"로 시작하면 광고로 읽힌다.

## 금지

- 단정·보장 표현. "반드시", "무조건", "적중률".
- 내부 용어. 브랜드 파일의 `voice.banned` 에 적어 두고 qa.py 가 잡는다.
- 겪지 않은 일을 겪은 것처럼 쓰기.
- 한 번에 여러 가지를 동시에 바꾸기. 변수는 하나씩 바꾼다.

| 내용 유형 | 쓸 레이아웃 | 피할 것 |
|---|---|---|
| 훅·질문 표지 | L2, L12, L1 | L6, L7 (표지에 표는 안 읽힌다) |
| 오해 교정 | L10, L2, L8 | L7 |

| 띠·별자리 순위 | L7, L11 | L9 |

### 돌려쓰기 규칙

- 한 묶음(캐러셀 한 세트) 안에서 같은 레이아웃을 절반 넘게 쓰지 않는다.
- 한 주 안에서 같은 레이아웃을 세 번 넘게 쓰지 않는다.
- 표지는 직전 게시물과 다른 레이아웃으로 고른다.
- 배경과 가독성 기법(T1~T4)도 같이 바꾼다. 레이아웃만 바꾸면 티가 난다.
- qa.py 가 묶음 안 쏠림을 잡는다. 주 단위 쏠림은 기획 때 본다.

## 2026-10-15 확정한 규칙 세 가지

1. 글자 외곽선 - 그림자는 계속 금지. 외곽선은 허용한다. 밝은 배경에서
   흰 글자가 사라지는 것을 막기 위해서다.
2. 표지 - 표지는 유지하되 1초 안쪽으로 둔다. 표지 문구 자체가 훅이어야 한다.
   인사나 로고를 먼저 두지 않는다.
3. 상단 고정 표기 - 유지한다. 다만 릴스 탭에서 UI와 겹치면 위치만 옮긴다.
