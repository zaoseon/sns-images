# 자오선 네이버 원고 보강 작업 규칙 (10/16 대표 지시)

대표 지시: "가급적 모든 원고에 여섯 운명학, 심리학 관련 내용이 들어가고 AI 브리핑 기준에 맞게 모바일 최적화와 롱테일 검색어 등 제대로 작업. 태그도 실제 검색 유입 반영하고 고려해서 확인."

심리 카드: `psych_cards.json` (48장, 근거 DOI는 Crossref로 확인된 것. **여기 있는 근거만 쓴다**)
키워드: `/home/claude/zaoseon-site/data/keywords/raw/psy_raw_2026-10-16.csv`(키워드,PC,모바일,합계,경쟁 — 월 검색량), `/home/claude/zaoseon-site/data/keywords/tag_research.json`, `/home/claude/zaoseon-site/data/keywords/raw/2026-10-08.json`(사주·운세 키워드 검색량)
실제 유입 검색어(네이버 크리에이터 어드바이저, 10/5 주): "2027년 토끼띠 운세", "자미두수 명반", "2027년 별자리 운세", "띠별 궁합", "별자리 운세", "2027년 소띠운세". 유입의 40%는 홈판, 검색 유입 49%(통합검색 모바일 28.5%, 블로그검색 모바일 14.8%). 제목 그대로 검색해 1~28위에 뜨는 글이 있음 → 롱테일 제목이 먹힌다.

출력: `out/<id>.json` 하나씩. 형식:

 "longtail": ["이 글이 노리는 롱테일 검색어 2~4개(띄어쓰기 있는 실제 검색 모양)"],
 "notes": "판단 근거 한두 줄(카드 고른 이유, 키워드 검색량 근거)"}

## 1. 심리학 단락 (has_psych가 false인 글 전부)
- 글 주제에 가장 맞는 카드 1장. 맞는 카드가 정말 없으면 null + notes에 이유.
- lines 3~4문장: ① "이런 마음을 심리학에서는 '{이론}'이라고 해요."처럼 개념 이름(카드 '이론') ② 카드 '습관말'·'그대로'를 이 글 장면에 맞게 풀어 쓴 한 문장 ③ 작은 행동 한 가지(이 글의 '해 볼 것'과 겹치지 않게, 카드 '신호'·'한마디' 참고) ④(선택) 한 줄 위로/정리.
- **연구 결과를 지어내지 않는다.** "~연구에서 밝혔어요"는 쓰지 않는다(카드에 연구 요약이 없음). 출처 줄로만 근거를 단다. source는 그 카드 근거[0]의 저자 성(첫 저자, 둘이면 "A & B", 셋 이상 "A 외"), 연도, 학술지 약칭, DOI를 **그대로** 옮긴다.
- 진단·치료 표현 금지(우울증·장애 등 병명 단정 금지). "상담" 대신 "코칭". 정월 말투: "~해요", 짧은 문장.
- before_heading: '이번에 해 볼 것' 류 소제목 번호(그 소제목 바로 앞에 넣는다). 없으면 FAQ 소제목 번호.

## 2. 여섯 운명학 단락 (lens_present에 없는 운명학을 넓혀 보기)
여섯 = 사주, 점성술(별자리), 수비학, 자미두수, 당사주, 하락이수. 이미 있는 것은 다시 쓰지 않는다.
- 라벨은 적용하는 쪽에서 붙인다("🔭 여섯 운명학으로 넓혀 보면"). lines 2~4문장.
- **쓸 수 있는 말만** (해석근거 조사에서 확인된 대응):
  - 자미두수: 태어난 시간까지 있어야 명반(12궁)이 나온다. 주제→궁: 성격·마음 = 명궁(+복덕궁=마음가짐), 연애·배우자 = 부처궁, 일 = 관록궁(학업·시험 포함), 돈 = 재백궁(흐름)·전택궁(모으기), 친구·동료 = 노복궁, 바깥 활동·이동 = 천이궁, 가족 = 부모·형제·자녀궁, 컨디션 = 질액궁(건강 단정 금지).
  - 당사주: 태어난 해·달·날·시로 열두 별 중 네 별을 뽑는다(해=초년, 달=중년, 날=말년, 시=평생). 주제→별(확인된 키워드만): 학문·글 = 천문성, 재능·예술 = 천예성, 복록·재물 = 천복성, 이동·밖의 일 = 천역성, 혼자·독립 = 천고성, 권세·리더 = 천권성, 명예·귀인 = 천귀성, 고비·단련 = 천액성, 변화 = 천파성, 장수·안정 = 천수성. 천간성·천인성은 쓰지 않는다. 배우자·자녀 단정 금지.
  - 하락이수: 사주 여덟 글자를 숫자로 바꿔 괘 하나(선천괘)를 세운다. 괘의 성질로 읽는다: 乾=굳셈, 坤=따름, 震=움직임, 巽=스며듦, 坎=빠짐·고비, 離=밝음·붙음, 艮=멈춤, 兌=기쁨·말. "원전에 이 주제 풀이가 있다"고 쓰지 않는다. 특정인 괘를 단정하지 않는다(예시 생년월일로 계산하지 않았으면 쓰지 않는다).
  - 점성술(별자리)·수비학·사주: 글 본문에 이미 쓰인 값을 반복하지 않는다. 새로 쓰려면 계산으로 확인되는 것만(날짜 별자리 경계, 생일 숫자 더하기).
- 마지막 문장은 "이 셋은 태어난 시간까지 있어야 계산돼서, 감정서에서 함께 겹쳐 봐요." 같은 안내(사실). 과장 금지.
- before_heading: 심리학 단락과 같은 자리(심리학 → 운명학 순서로 적용하면 운명학이 먼저 나오게 적용 쪽이 처리).

## 3. 롱테일 검색어 · 제목 · 소제목 · 태그
- **status=발행 글은 title을 바꾸지 않는다(null).** 예약·미발행은 바꿀 수 있다: 공백 포함 40자 이내, 앞쪽에 주 검색어, 뒤에 롱테일(질문형·구체 상황). 지금 제목이 이미 좋으면 null.
- 롱테일 근거: psy_raw csv·2026-10-08.json의 검색량(월 30회 이상이 이상적), tag_research의 관련키워드, 위 실제 유입 검색어 모양("2027년 X띠 운세", "자미두수 명반"처럼 연도+띠+운세, 용어+구체어).
- headings: 질문형 소제목 중 1~2개를 롱테일 질문 모양으로 다듬을 수 있다(본문 내용 안에서). **짧게: 번호 포함 한글 13자 안팎**(폰 한 줄). 없으면 [].
- tags 10개: 띄어쓰기 없는 실제 검색어 모양. ① 검색량 있는 정확한 검색어 3~4개(경쟁 '낮음·중간' 우선) ② 롱테일 2~3개 ③ 이 글 고유어 2개 ④ 마지막은 "자오선". **본문에 나오는 말만**(N10). 검색량 0이거나 너무 넓은 '운세' 단독은 빼기. notes에 고른 태그 중 검색량을 아는 것은 숫자를 적는다.

## 4. 공통 금지
- 지어낸 경험·후기·통계 금지. 이 글 본문에 없는 사실 단정 금지.
- 줄표(—)·"엔진"·"초안" 금지. 영어 문장 금지.
- 문장은 짧게(폰 기준 한 문장 40자 안팎).
