# 정월 비주얼 방향 3안 시안 v3 (2026-10-10)
주제: "3초 만에 사랑에 빠지는 사람"(10/10 18:30 예약 글의 값). 세 안은 구성 문법이 다르다. 강조색은 같다(금).
- VD-A Editorial Scene(4장): 큰 글 두 덩어리, 위와 아래에 나눠 둔다. 정월은 표지에서만(1/4).
- VD-B Utility Chart(4장): 사주·별자리·숫자 비교표가 본체. 정월은 마지막 장(1/4).
- VD-C Micro Story(5장): 말풍선 대화 흐름. 정월 얼굴은 1컷과 5컷(2/5 = 40%).
## 만든 방법 (v2의 잘못을 바로잡음)
- v2는 좌표를 눈대중으로 정해 R21·R29 간격을 어겼다. v3는 `pipeline/template_engine.Page`(카드 안전영역 검증)로 만들고, 세로 위치는 블록 높이를 더해 계산한다.
- 묶음은 상단 문구 아래 75px(y183) ~ 주소 위 75px(y1265), 가운데 y724. 글 덩어리 사이 40px 이상, 그림·박스와 글 사이 60px 이상.
- 박스 안 글은 정중앙, 안쪽 여백 36/28px(R18·R28). 본문 44px 이상, 굵기 800 이상.
- 만들 때마다 엔진 검증 + 배치 검산(위·아래·가운데) + `style_spec.check_page`를 자동으로 돌린다. 한 건이라도 걸리면 문제로 출력한다.
- 쓰는 말: "사주·별자리·숫자". "지도" 비유는 금지(대표 10/4).
## 아직 확인 못한 것
- B3 "첫눈에 빠지는 쪽에 가까울 수 있어요"는 새로 쓴 문장이다. 풀이 근거를 확인해야 한다.
- C2 대화는 지어낸 상황 대사다.
