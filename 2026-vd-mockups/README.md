# 정월 비주얼 방향 3안 시안 v2 (2026-10-10)
v1은 저장소의 카드 제작 규칙(R01~R36)과 카드 도구를 쓰지 않고 따로 그려서 폐기했다. v2는 `pipeline/card_kit.py`(배경·정월 컷·말풍선·휴대폰), `brand_frame`(R01~R03 상단 문구·주소·AI 고지), `fonts_kit`(R05 페이퍼로지·프리텐다드)와 `style_spec.check_page`(글자 크기·굵기·줄간격·대비·겹침·위아래 배치 자동 검사)로 만들었다. 검사 문제 0건.
주제: "3초 만에 사랑에 빠지는 사람"(10/10 18:30 예약 글의 값. 사주 병화·도화, 별자리 양자리·사자자리, 수비학 3번·5번). "세 지도"는 사주·별자리·수비학이라는 기존 용어를 그대로 쓴다.
- VD-A Editorial Scene(4장): 제목은 위, 설명은 아래, 가운데는 브랜드 차트 배경이 비어 있는 큰 여백. 정월은 표지에만(1/4).
- VD-B Utility Chart(4장): 세 지도 교차표가 본체, 정월은 마지막 장에 작게(1/4).
- VD-C Micro Story(5장): 말풍선 대사 흐름. 정월은 1컷과 5컷만(2/5=40%, R19). 중간 컷은 휴대폰 소품과 말풍선.
