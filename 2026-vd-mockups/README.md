# 정월 비주얼 방향 3안 시안 (2026-10-10)
같은 주제 1편("연락을 기다리다 지치는 밤")을 구성 문법이 다른 3안으로 각 4장(1080x1440). `python3 build.py [출력폴더]`로 다시 만든다.
- VD-A Editorial Scene: 여백 60%, 명조 제목 1~2줄, 정월은 작게(표지에만), 도식은 자오선 선과 점 하나
- VD-B Utility Chart: 표가 본체, 결론은 상단, 정월은 작은 아바타(1장)
- VD-C Micro Story: 정월이 주인공 70%, 대사체, 컷마다 배경색이 따뜻함→차가움→강조색으로 이동
강조색은 3안 모두 같은 값(#E0A83E)이다. 배경 계열은 안의 성격에 따라 다르다(A·C 어두움, B 밝은 중립). 표 값과 문안은 시안용 예시이고 계산 검증 전이다. 이 색·폰트는 공식이 아니다(R38).
